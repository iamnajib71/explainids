Candidate alerts · model needs local validation. A prediction or high confidence does not prove an attack. Unlabelled traffic has no measured accuracy, precision or recall.

Feed is disconnected. With no server key, local development access is open; keep the app bound to localhost.

Set up a collector
  1. Start the local app with a saved trained detector. Synthetic demo mode cannot accept sensor batches.
  2. On the host you own and are allowed to monitor, list interfaces and explicitly choose the intended interface in the sensor command-line tool.
  3. Run a bounded capture and the compatible flow extractor on that host, then submit the extracted CSV to /sensor/ingest with the same API key.
  4. Use the local setup guide for the exact command and prerequisites. The app never starts capture remotely. Monitor only traffic you are authorised to collect.

Source addresses are pseudonymised by this server. Capture counts and origin are sender-reported. The in-memory feed resets when the app restarts; each server worker has its own feed.
